Fatebringer from "Destiny"

October 2025

Destiny might be one of my top five favorite video games ever played growing up (Destiny 1 that is), so I wanted to make something from it.

This project was my first experience trying to use an airbrush. I ran into a lot of issues with paint splattering, chipping off, etc. This is also my first time attempt to do a "weathering" effect to my props. This is very far from perfect but I felt like documenting this as I hope to seriously improve my airbrush skills in the future.

Additionally, I have complaints about this model, which will only drive my motivation to make my own models.
